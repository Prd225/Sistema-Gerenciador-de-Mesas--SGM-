# Arquivos Legados (v6.x)

Esta pasta contém o protótipo e versão anterior do **Sistema Gerenciador de Mesas (SGM v6.x)**, desenvolvido como uma página HTML única com scripts JavaScript puros e estilos CSS clássicos (`DM_tool_6v.html`, `js/app.js` e `css/styles.css`).

> ℹ️ **Nota**: Estes arquivos foram arquivados para referência histórica e **não fazem parte** da aplicação React em produção (`src/`), que roda a partir de `index.html` e `src/main.tsx`.
